# adrian-ramlal.github.io

My personal website: plain HTML and CSS, served by GitHub Pages at https://adrian-ramlal.github.io. The paper pages live in their own repos ([persistgs](https://github.com/adrian-ramlal/persistgs), [inverse-material](https://github.com/adrian-ramlal/inverse-material)) and are served under the same domain.

To preview it locally, run `python3 -m http.server` in this folder and open http://localhost:8000.
